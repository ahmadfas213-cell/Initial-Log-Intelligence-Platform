# Log Intelligence Platform

A browser-based log viewer and analyzer. Load a text log file to get a summary of its events and identify entries that may need attention.

## Features
- Upload or drag and drop .log and .txt files.
- Load a sample log to try the interface.
- Parse log events locally in the browser.
- Count total events, errors, warnings, and critical entries.
- Show detected IP addresses and an anomaly score.
- Review event severity distribution and dashboard summaries.
- Export parsed results as CSV.

## Run locally

~~~bash
git clone https://github.com/ahmadfas213-cell/Initial-Log-Intelligence-Platform.git
cd Initial-Log-Intelligence-Platform
~~~

Open index.html in a browser or serve the folder with a local static server.

## Stack
HTML, CSS, and JavaScript.

Log files are processed in the browser. The anomaly score is an indicator generated by the current analyzer, not a replacement for a dedicated SIEM or incident-response workflow.
